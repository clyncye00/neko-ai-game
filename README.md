# 猫、混ざってます。

AI画像生成の「猫混入バグ」を直す、スマートフォン向け20秒ミニゲーム。前作とは独立した新企画です。

## 遊び方

9マスの中から猫だけをタップ。猫以外を触ると20点減点です。
最初のタップで20秒開始。猫を全部消すと50点ボーナスとともに次の生成画像へ。
猫だけを連続で修正すると最大5倍。AIは修正のたびに苦しい言い訳をします。
結果画面の「もう一度、修正する」で再開できます。

## 起動

index.htmlを開くだけで遊べます。静的ホスティング対応、ビルド・インストール不要です。
Vercelで公開するときは、このフォルダーをリポジトリ直下に配置してImportしてください。
前作の公開先とは別のリポジトリ・プロジェクトにします。

## 構成

- engine.js：テーマ、抽選、スコア、コンボ、制限時間。
- game.js：操作、表示、AIの言い訳。
- style.css：縦画面レイアウト、軽量な演出。

AIはゲーム内の演出です。実際のAI API・通信・音声・広告・保存機能はありません。
絵文字は端末標準のため、iPhoneとAndroidで見た目が少し異なります。
「動きを減らす」の端末設定に対応。iPhone Safari / Android Chromeの実機確認は未実施です。
